# Paisa Desk

Personal money manager: spends, budgets, loans and net worth from bank, Paytm and CIBIL statements.

Live: https://sagarchakraborty-creator.github.io/paisa-desk/

Statements are read inside the app on the device (pdf.js, SheetJS). Nothing is uploaded; data is stored
encrypted (AES-GCM, key from your passcode) in the browser. This repo holds code only.
